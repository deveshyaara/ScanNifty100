# Or install individually

## ETL Environment Variables

Create `.env` file in project root:

```env
# Database
DATABASE_URL=postgresql://user:password@localhost:5432/scannifty100

# ETL Settings
ETL_LOG_DIR=data/logs
ETL_RAW_DIR=data/raw
ETL_CLEAN_DIR=data/clean

# Celery
CELERY_BROKER_URL=redis://localhost:6379/0
CELERY_RESULT_BACKEND=redis://localhost:6379/0
```

## Data Flow

```
data/source/*.xlsx
         ↓
    [Script 01: Extract]
         ↓
data/raw/*.csv (raw, unmodified extraction)
         ↓
    [Script 02: Transform]
         ↓
data/clean/*.csv (standardized, validated, derived metrics added)
         ↓
    [Script 03: Load]
         ↓
PostgreSQL Warehouse (dim_* and fact_* tables)
         ↓
Power BI / Django API / Analytics
```

## Troubleshooting

### Error: openpyxl not found
```bash
pip install openpyxl
```

### Error: sector_mapping.csv not found
Make sure `data/reference/sector_mapping.csv` exists with all 92 companies mapped.

### Error: Year format not standardized
Check `data/logs/02_transform.log` for warnings about unknown year formats.
Look for "Unknown year format:" entries.

### Error: Infinity values in derived metrics
This indicates division by zero. Check the safe_divide function is being used.
Review `data/logs/02_transform.log` for details.
